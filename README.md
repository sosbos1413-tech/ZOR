# HIDEOUT — سيد المخبأ

**لعبة جوال: ابنِ مخبأ عصابتك غرفة بعد غرفة، ثم دافع عنه بالتصميم لا بالأرقام.**

> مخبأ متوسط الأدوات بترتيب عبقري يتفوق على مخبأ بأقوى الغرف وتصميم سيّئ.

تبدأ بقبو صغير وبابٍ واحد وشخصين. تبني الغرف على شبكة، وتوزّع الطاقم والطاقة
والدفاعات، ثم يهاجمك خصوم **يسلكون المسار الحقيقي داخل التصميم الذي بنيته** —
فيلتفّون حول دفاعاتك القوية، ويقصدون أضعف طريق إلى هدفهم.

- عمودي 9:16، باللمس، بإبهام واحد.
- ملف واحد مكتفٍ ذاتيًا: بلا مكتبات، بلا build step، ويعمل **بدون إنترنت**.
- تقدّمك يُحفظ تلقائيًا في المتصفح.

📄 وثيقة التصميم الكاملة: [`docs/game-design-document.md`](docs/game-design-document.md)

---

## كيف تلعب

**١. أسهل طريقة — من المتصفح**

نزّل [`index.html`](index.html) وافتحه في أي متصفح. هذا كل شيء.

**٢. كتطبيق أندرويد (APK)**

1. تبويب **Actions** → **Build APK** → افتح آخر تشغيل ناجح.
2. من أسفل الصفحة نزّل **HIDEOUT-apk**، وداخله `HIDEOUT.apk`.
3. على الجوال: افتح الملف واسمح بـ«التثبيت من مصادر غير معروفة».

**٣. رابط دائم عبر GitHub Pages**

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.
بعد دقيقة تصير اللعبة على `https://sosbos1413-tech.github.io/hideout/`.

## أهم ما في اللعبة

| النظام | الفكرة |
|---|---|
| **الشبكة والتوسعة** | أشكال غرف غير منتظمة قابلة للتدوير. التوسعة تعرض ٣ أشكال عشوائية تختار منها وتختار مكانها — فكل جولة تنتج مخبأً مختلفًا. |
| **علاقات الغرف** | ٢٨ غرفة عبر ٧ فئات، بمكافآت وعقوبات حسب الجوار: ورشة+مخزن تسرّع الإنتاج، مولد+غرفة نوم يخفض المعنويات. |
| **الطاقة** | إنتاج مقابل استهلاك، وأولوية لكل غرفة تحددها أنت، وبطارية تغطي العجز مؤقتًا. |
| **الفخاخ** | ٦ فخاخ، أذكاها **غرفة الخداع**: تجعل جناحًا كاملًا يبدو ضعيفًا فتجذب المهاجمين إليه ثم تؤذيهم. |
| **المداهمة** | قتال تلقائي يسلك أقصر طريق مقاومة عبر تصميمك، مع ٧ أوامر تكتيكية محدودة أثناء المعركة. |
| **الزعماء** | ٥ زعماء، كل واحد يغيّر قاعدة: أحدهم يدخل من مدخلين، وآخر يقطع الكهرباء دوريًا، وثالث يُبطل الاستطلاع تمامًا. |
| **الطبقات** | ⚡ الطاقة و🧭 المسار المتوقع و⚠️ نقاط الضعف — تريك أخطاء تصميمك قبل أن يستغلها العدو. |
